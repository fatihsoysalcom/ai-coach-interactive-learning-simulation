# AI Coach Interactive Learning Simulation

This example simulates a basic interactive AI coach, similar to the GenaAIGemmaCoach concept described in the article. It demonstrates a conversational learning experience where the "coach" provides information and asks follow-up questions on topics like Artificial Intelligence. The core logic for generating dynamic responses would be replaced by a real Large Language Model (like Google's Gemma) in a production environment.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Interact with the AI coach by typing your questions in Turkish or English.
